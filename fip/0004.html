    What the terms mean
    FIP
    Filecoin Improvement Proposal: a written proposal to change the protocol, its standards or the governance process.
    FRC
    Filecoin Request for Comments: a standard or convention, such as a token standard, API or data format, that tools and apps can follow. FRCs don't change the protocol, so they don't ship in a network upgrade.
    Draft
    The FIP has a number and is being refined in the open. Anyone can comment.
    Last Call
    A final review window, normally 14 days, before the FIP is Accepted (core) or Final (everything else).
    Accepted
    A core FIP approved for implementation. It ships in a network upgrade, then becomes Final.
    Final
    Done: implemented and adopted. Only errata are fixed from here.
    Core Devs
    The regular open meeting where implementation and research teams discuss FIPs and upgrade priorities.
    Network upgrade
    A scheduled change to the protocol that all nodes adopt at a set epoch, named NV followed by a number (NV30).
    Epoch
    One 30-second slot of the Filecoin chain. Upgrades activate at a specific epoch.
    Implementers
    The teams that build Filecoin node software (such as Lotus, Venus and Forest) and ship upgrades.
    FIP editor
    Maintainers of the FIPs repo who check proposals for format and move them between statuses.
